# 🎽 Groupes

{% hint style="info" %}
En utilisant la commande _<mark style="color:violet;">/arena party \<Pseudos></mark>_, vous avez la possibilité de créer un groupe avec d'autres joueurs. Si vous êtes invités à rejoindre un groupe, vous pourrez effectuer la commande _<mark style="color:violet;">/arena join \<Pseudo></mark>_ pour accepter l'invitation.

Le chef du groupe pourra alors en cliquant sur l'item permettant de rejoindre l'arène choisir entre lancer un **FFA** entre les joueurs de son groupe ou un **combat en 2 équipes**.
{% endhint %}

{% tabs %}
{% tab title="FFA" %}
Le mode **FFA** vous permet d'être téléportés dans une arène et de vous battre jusqu'à ce qu'il ne reste qu'un seul survivant.

Quand vous mourrez, vous êtes placé en **spectateur** jusqu'à la fin du combat.
{% endtab %}

{% tab title="Équipes" %}
Dans ce mode, les joueurs sont répartis en 2 équipes égales dans une arène (si vous êtes un nombre impair, un joueur est placé seul avec quoi qu'il arrive un **rôle solitaire** ou **à alliance potentielle**).

Par défaut, vous devez gagner avec **votre ou vos coéquipiers** mais cette condition peut changer si vous possédez l'un des **rôles solitaires** de l'arène (voir la liste ci-dessous). Certains rôles peuvent également être **en alliance** selon certaines conditions (voir les conditions dans les fiches de rôles).
{% endtab %}
{% endtabs %}

{% hint style="info" %}
Vous pouvez quitter un groupe avec la commande _<mark style="color:violet;">/arena leave</mark>_ (si vous étiez le chef du groupe, un membre aléatoire du groupe deviendra le nouveau chef du groupe).

Vous pouvez dissoudre un groupe avec la commande _<mark style="color:violet;">/arena disband</mark>_ (seul le chef actuel du groupe peut effectuer cette commande).
{% endhint %}

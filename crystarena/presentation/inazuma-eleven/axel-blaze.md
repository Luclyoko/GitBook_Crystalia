# 🟡 Axel Blaze

## Effets

{% hint style="success" %}
Vous disposez de l'effet <mark style="color:blue;">**Strength 1**</mark> permanent.
{% endhint %}

## Pouvoirs

{% hint style="warning" %}
<mark style="color:orange;">**Tornade de Feu**</mark> _(cooldown : 2min30)_

Vous permet d'obtenir l'effet <mark style="color:blue;">**Fire Resistance**</mark> pendant 1 minute ainsi que de **voler** tant que vous n'avez pas subit de dégâts en volant.
{% endhint %}

{% hint style="info" %}
Vous avez **10%** de chances d'**enflammer** vos adversaires à l'épée.
{% endhint %}

# 🟢 Sabito

## Effets

{% hint style="success" %}
Vous disposez de l'effet <mark style="color:blue;">**Speed 1**</mark> permanent.

Vous possédez une [<mark style="color:green;">**Lame de Nichirin**</mark>](./#lame-de-nichirin).
{% endhint %}

## Pouvoirs

{% hint style="warning" %}
<mark style="color:blue;">**Veille**</mark> _(cooldown : 2min30)_

Vous permet de retirer un effet aléatoire au joueur visé pendant **40 secondes**.
{% endhint %}

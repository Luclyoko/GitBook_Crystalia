# 🟠 Shinjuro

## Effets

{% hint style="info" %}
Vous disposez des effets <mark style="color:blue;">**Strength 1**</mark> et <mark style="color:blue;">**Fire Resistance**</mark> permanents.
{% endhint %}

## Pouvoirs

{% hint style="warning" %}
<mark style="color:$warning;">**Alcool**</mark> _(activable/désactivable)_

Tant que ce pouvoir est actif, tous les **5 coups**, vous infligez un effet de <mark style="color:blue;">**Fire Aspect**</mark> dont la puissance est **évolutive** : tous les **3 coups en feu infligés**, la puissance de ce dernier **augmente** (le temps entre **deux ticks de feu est réduit de moitié** ou les **dégâts infligés par le feu doublent** en alternance).&#x20;

Vous voyez la puissance de votre feu dans votre action bar.

Chaque dégât de feu que vous **infligez** grâce à ce pouvoir vous **régénère d'1/2❤**.
{% endhint %}

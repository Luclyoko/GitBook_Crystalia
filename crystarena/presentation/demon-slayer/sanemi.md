# 🟢 Sanemi

## Effets

{% hint style="success" %}
Vous disposez des effets <mark style="color:blue;">**Speed 1**</mark> le jour et <mark style="color:blue;">**Speed 2**</mark> la nuit.

Vous possédez une [<mark style="color:green;">**Lame de Nichirin**</mark>](./#lame-de-nichirin).
{% endhint %}

## Pouvoirs

{% hint style="warning" %}
<mark style="color:yellow;">**Dispersion**</mark> _(cooldown : 2min)_

Vous permet de **disperser** aléatoirement sur la carte tous les joueurs en échange de **2❤** permanents (vous récupérez 1❤ par minute).
{% endhint %}

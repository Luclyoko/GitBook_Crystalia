# 🔴 Reborn

## Particularités

{% hint style="info" %}
Si [<mark style="color:$danger;">**Tsuna**</mark>](tsuna.md) est présent dans l'arène, vous pouvez jouer en alliance et verrez une pastille de couleur dans son pseudo.
{% endhint %}

## Effets

{% hint style="success" %}
Vous disposez des effets <mark style="color:blue;">**Speed 2**</mark> et <mark style="color:blue;">**Resistance 1**</mark> permanents.
{% endhint %}

{% hint style="danger" %}
Vous possédez <mark style="color:red;">**2❤**</mark> permanents **en moins**.
{% endhint %}

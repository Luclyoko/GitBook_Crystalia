# 🔴 Tsuna

## Particularités

{% hint style="info" %}
Si [<mark style="color:$danger;">**Reborn**</mark>](reborn.md) est présent dans l'arène, vous pouvez jouer en alliance et verrez une pastille de couleur dans son pseudo.
{% endhint %}

## Effets

{% hint style="success" %}
Vous disposez de l'effet <mark style="color:blue;">**Strength 1**</mark> permanent ainsi que de l'effet <mark style="color:blue;">**Speed 1**</mark> tant que [<mark style="color:yellow;">**Reborn**</mark>](reborn.md) est en vie.
{% endhint %}

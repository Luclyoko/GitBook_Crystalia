# 🔴 Loup-Garou

## Particularités

{% hint style="info" %}
Il peut y avoir plusieurs <mark style="color:$danger;">**Loups-Garous**</mark> dans l'arène qui forment alors une **meute**, peuvent jouer **en alliance** et se voient avec une **pastille rouge entre eux**.
{% endhint %}

## Effets

{% hint style="success" %}
Vous disposez de l'effet <mark style="color:blue;">**Strength 1**</mark> la nuit.
{% endhint %}

{% hint style="danger" %}
Chaque kill vous rapporte **2 minutes** de <mark style="color:blue;">**Speed 1**</mark>.
{% endhint %}

# 🟣 Cupidon

## Particularités

{% hint style="info" %}
À votre apparition, vous avez **20%** de chance de former un <mark style="color:violet;">**couple**</mark> avec un joueur aléatoire, vous voyez alors tous deux une pastille de couleurs dans vos pseudos, obtenez un pouvoir vous permettant via un clic-droit, de vous faire un don de <mark style="color:red;">**2**</mark><mark style="color:red;">**❤**</mark>. Si l'un de vous meurt, il emporte l'autre avec lui.
{% endhint %}

## Items

{% hint style="info" %}
Vous disposez d'un arc enchanté <mark style="color:purple;">**Power 3**</mark> et <mark style="color:purple;">**Punch 1**</mark> ainsi que de <mark style="color:purple;">**32 flèches**</mark> supplémentaires.
{% endhint %}

## Pouvoirs

{% hint style="danger" %}
Au bout de **5 kills**, votre arc obtient une **amélioration** lui conférant l'enchantement <mark style="color:purple;">**Punch 2**</mark>.
{% endhint %}

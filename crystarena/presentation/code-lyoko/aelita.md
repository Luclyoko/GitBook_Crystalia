# 🩷 Aelita

## Particularités

{% hint style="info" %}
Si [<mark style="color:blue;">**Jérémie**</mark>](jeremie.md) est présent dans l'arène, vous pouvez jouer en alliance et verrez une pastille de couleur dans son pseudo.

{% hint style="danger" %}
Attention car [<mark style="color:$danger;">**X.A.N.A.**</mark>](x.a.n.a..md) peut prendre son apparence.
{% endhint %}
{% endhint %}

## Effets

{% hint style="success" %}
Vous disposez de l'effet <mark style="color:blue;">**Resistance 1**</mark> permanent.

Vous possédez une barre de <mark style="color:yellow;">**points d'énergie (PE)**</mark>. Cette barre commence à <mark style="color:yellow;">50PE</mark>, a un maximum de <mark style="color:yellow;">100PE</mark> et se recharge au rythme d'**un&#x20;**<mark style="color:yellow;">**PE**</mark>**/seconde**.
{% endhint %}

## Pouvoirs

{% hint style="warning" %}
<mark style="color:pink;">**Bouclier**</mark> _(coût : <mark style="color:yellow;">30PE</mark>)_

Vous permet, à l'aide d'un clic-droit, d'**esquiver les 3 prochains coups**.
{% endhint %}

{% hint style="warning" %}
<mark style="color:pink;">**Champ de Force**</mark> _(coût : <mark style="color:yellow;">20PE</mark>)_

Vous permet, **en restant immobile et en restant appuyé sur votre clic-droit**, de charger votre **Champ de Force**. Lorsque vous le relâchez, pour **chaque seconde** passée à le charger s'ajoute **1❤ de dégât**. Il part alors droit dans la direction que vous regardez à une vitesse de **5 blocs/seconde** et **explose à l'impact** contre un joueur ou un mur, **infligeant alors les dégâts chargés au joueur touché** et infligeant également le **même nombre de dégâts répartis entre les joueurs se trouvant dans un rayon de 5 blocs** de l'impact.
{% endhint %}

# ⚫ William

## Particularités

{% hint style="info" %}
Si [<mark style="color:$danger;">**X.A.N.A.**</mark>](x.a.n.a..md) est présent dans l'arène, vous pouvez jouer en alliance et voyez une pastille de couleur dans son pseudo.
{% endhint %}

## Items

{% hint style="info" %}
Vous possédez une épée en diamant <mark style="color:blue;">**Sharpness 4**</mark>.
{% endhint %}

## Effets

{% hint style="success" %}
Vous disposez de l'effet <mark style="color:blue;">**Resistance 1**</mark> permanent.

Si vous parvenez à tuer [<mark style="color:$info;">**Yumi**</mark>](yumi.md) de votre main, vous obtiendrez l'effet <mark style="color:blue;">**Strength 1**</mark> permanent.

Vous possédez une barre de <mark style="color:yellow;">**points d'énergie (PE)**</mark>. Cette barre commence à <mark style="color:yellow;">50PE</mark>, a un maximum de <mark style="color:yellow;">100PE</mark> et se recharge au rythme d'**un&#x20;**<mark style="color:yellow;">**PE**</mark>**/seconde**.
{% endhint %}

## Pouvoirs

{% hint style="warning" %}
<mark style="color:$info;">**Super Smoke**</mark> _(coût : <mark style="color:yellow;">30PE</mark>)_

Vous permet, à l'aide d'un clic-droit, de devenir pendant **4 secondes** une **traînée de particules noires et de voler**. Vous ne pouvez pas **frapper les joueurs ni être frappé** pendant cette période.
{% endhint %}

{% hint style="warning" %}
<mark style="color:$info;">**Esquive**</mark> _(coût : <mark style="color:yellow;">40PE</mark>)_

Ce pouvoir s'active automatiquement dès que vous subissez un coup mortel.

Vous vous **téléportez dans le dos** de votre tueur à environ **7 blocs** de distance en laissant une **traînée de particules derrière vous** et êtes **régénéré de la moitié de votre vie** si vous parvenez à le **frapper en premier**.
{% endhint %}

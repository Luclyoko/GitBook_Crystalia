# 🟣 Odd

## Effets

{% hint style="success" %}
Vous disposez de l'effet <mark style="color:blue;">**Speed 1**</mark> permanent.

Vous possédez une barre de <mark style="color:yellow;">**points d'énergie (PE)**</mark>. Cette barre commence à <mark style="color:yellow;">50PE</mark>, a un maximum de <mark style="color:yellow;">100PE</mark> et se recharge au rythme d'**un&#x20;**<mark style="color:yellow;">**PE**</mark>**/seconde**.
{% endhint %}

## Pouvoirs

{% hint style="warning" %}
<mark style="color:purple;">**Bouclier**</mark> _(coût : <mark style="color:yellow;">30PE</mark>)_

Vous permet, à l'aide d'un clic-droit, d'**esquiver les 3 prochains coups**.
{% endhint %}

{% hint style="warning" %}
<mark style="color:purple;">**Flèche Laser**</mark> _(coût : <mark style="color:yellow;">20PE</mark>)_

Vous permet, à l'aide d'un clic-droit, de **tirer une flèche** partant droit infligeant **1/2❤ de dégâts tous les 7 blocs** parcourus (maximum 4❤ de dégâts) et traversant l'<mark style="color:blue;">**Absorption**</mark>.
{% endhint %}

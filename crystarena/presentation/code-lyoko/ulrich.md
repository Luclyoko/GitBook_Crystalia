# 🟡 Ulrich

## Particularités

{% hint style="info" %}
Si [<mark style="color:$info;">**Yumi**</mark>](yumi.md) est présente dans l'arène, vous pouvez jouer en alliance et voyez une pastille de couleur dans son pseudo.

{% hint style="danger" %}
Attention car [<mark style="color:$danger;">**X.A.N.A.**</mark>](x.a.n.a..md) peut prendre son apparence.
{% endhint %}
{% endhint %}

## Items

{% hint style="info" %}
Vous possédez une épée en diamant <mark style="color:blue;">**Sharpness 4**</mark>.
{% endhint %}

## Effets

{% hint style="success" %}
Vous disposez de l'effet <mark style="color:blue;">**Speed 1**</mark> permanent.

Vous possédez une barre de <mark style="color:yellow;">**points d'énergie (PE)**</mark>. Cette barre commence à <mark style="color:yellow;">50PE</mark>, a un maximum de <mark style="color:yellow;">100PE</mark> et se recharge au rythme d'**un&#x20;**<mark style="color:yellow;">**PE**</mark>**/seconde**.
{% endhint %}

## Pouvoirs

{% hint style="warning" %}
<mark style="color:yellow;">**Super Sprint**</mark> _(coût : <mark style="color:yellow;">1PE</mark>/niveau et par seconde)_

Vous pouvez, à l'aide d'un clic-gauche, **augmenter** d'un niveau votre **Super Sprint** et à l'aide d'un clic-droit le **réduire** d'un niveau.

Pour chaque niveau de **Super Sprint**, votre effet de <mark style="color:blue;">**Speed**</mark> augmente d'un niveau mais le coût en <mark style="color:yellow;">**PE**</mark> augmente également.
{% endhint %}

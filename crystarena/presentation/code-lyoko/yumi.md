# ⚫ Yumi

## Particularités

{% hint style="info" %}
Si [<mark style="color:yellow;">**Ulrich**</mark>](ulrich.md) est présent dans l'arène, vous pouvez jouer en alliance et verrez une pastille de couleur dans son pseudo.

{% hint style="danger" %}
Attention car [<mark style="color:$danger;">**X.A.N.A.**</mark>](x.a.n.a..md) peut prendre son apparence.
{% endhint %}
{% endhint %}

## Effets

{% hint style="success" %}
Vous disposez de <mark style="color:blue;">**10%**</mark> de <mark style="color:blue;">**Speed**</mark>, <mark style="color:blue;">**Strength**</mark> et <mark style="color:blue;">**Resistance**</mark> permanents.

Vous possédez une barre de <mark style="color:yellow;">**points d'énergie (PE)**</mark>. Cette barre commence à <mark style="color:yellow;">50PE</mark>, a un maximum de <mark style="color:yellow;">100PE</mark> et se recharge au rythme d'**un&#x20;**<mark style="color:yellow;">**PE**</mark>**/seconde**.
{% endhint %}

## Pouvoirs

{% hint style="warning" %}
<mark style="color:$info;">**Télékinésie**</mark> _(coût : <mark style="color:yellow;">30PE</mark>)_

Vous permet, à l'aide d'un clic-droit, de **bloquer les mouvements** du joueur ciblé, l'empêchant alors de **changer de slot d'inventaire** pendant **5 secondes**.
{% endhint %}

# 🟡 Gollum

## Particularités

{% hint style="info" %}
Si [<mark style="color:yellow;">**Bilbon**</mark>](bilbon.md) est présent dans l'arène, vous pouvez jouer en alliance et verrez une pastille de couleur dans son pseudo.
{% endhint %}

## Effets

{% hint style="success" %}
Vous disposez de <mark style="color:red;">**2❤**</mark> permanents supplémentaires ainsi que de l'effet <mark style="color:blue;">**Strength 1**</mark> tant que [<mark style="color:yellow;">**Bilbon**</mark>](bilbon.md) est en vie.
{% endhint %}
